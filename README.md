## <https://themanronin.github.io/>

- [CIPHER](https://themanronin.github.io/CIPHER/) — 加密 / 解密工具箱。对称加密支持 AES-256-GCM 与 XChaCha20-Poly1305，PBKDF2 / Argon2id 密钥派生；非对称混合加密支持 X448 + ML-KEM-1024，含公私钥生成与 JSON 密钥管理。

- [Password Generator](https://themanronin.github.io/PasswordGenerator/) — 密码生成器。自定义长度与字符组合，可排除相似字符、避免连续重复，实时评估熵值强度。
- [Word Count](https://themanronin.github.io/wordcount/) — 字数统计工具。实时统计字符、空白字符、英文单词、行数与段落数，并估算阅读时长。

- [LiquidGlass](https://themanronin.github.io/LiquidGlass/) — 实时玻璃折射效果模拟器。基于 WebGL 与 GLSL 着色器，支持折射、RGB 色散、放大、背景模糊与边缘高光等可交互参数。

- [DevToolboxPro](https://themanronin.github.io/DevToolboxPro/) — 全能开发者工具箱。编解码、哈希、加解密、生成器、格式转换、JSON ⇄ TypeScript、Markdown ⇄ HTML、JWT 签发与校验等。

- [Calendar](https://themanronin.github.io/Calendar/) — 排班日历。月视图排班，支持白班 / 夜班 / 休班 / 请假 / 加班，内置默认班次规则，支持文本导入、JSON / CSV 导出、JSONBin 云同步与周期统计。

- [WebhookForwarder](https://themanronin.github.io/WebhookForwarder/) — Webhook 发送器。企业微信群机器人文本消息发送，支持代理转发（`{url}` 占位符）、请求预览、响应查看与发送记录。

- [SyncText](https://themanronin.github.io/SyncText/) — 云同步临时记事本。基于 JSONBin 云端存储，内容刷新即清空、仅云端留存；云端为空时上传本地内容，本地空白或未改动时拉取云端内容，两边不一致时弹窗选择保留哪一份。支持字符 / 行数统计、高度拖拽调整与深色模式。
